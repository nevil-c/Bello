# Bello hospital dashboard

Local faster-whisper transcription, patient requests, shared department inbox and satisfaction storage. See [TRANSCRIPT_SETUP.md](TRANSCRIPT_SETUP.md) for installation, API behavior and Raspberry Pi testing.

## Cloud archive (optional)

Set BELLO_CLOUD_URL, BELLO_CLOUD_API_KEY and BELLO_SITE_ID to copy finished request records to the AWS archive in [../aws-backend](../aws-backend/README.md). Audio never leaves the Pi.
