# AI Call Bell Router

Bedside touchscreen kiosk for hospital inpatients (Ops Unleashed Hackathon, Challenge 2: Inpatient).
Patients type or speak a request; a fine-tuned classifier routes it to the right department so
non-clinical requests (water, pillows, TV) skip the nurse and urgent clinical requests reach the
nurse immediately.
